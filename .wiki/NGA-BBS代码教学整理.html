1color 颜色

语法

[color=颜色名]文本[/color]

用途

  • 醒目的颜色一般和粗体等格式一起使用，标注醒目或重要的内容
  • 最好不要使用过多的颜色，以免整篇文字太花，反而不利于阅读
  • 同级的标题或者相似结构的文本，最好使用同样的颜色或格式

效果预览

[color=skyblue]frost[/color] 与 [color=red]fire[/color] A song of frost and fire.

2size 字号

语法

[size=百分比]文本[/size]

用途

  • 按百分比缩放字号；默认 100%，最小 1%，最大……很大
  • 一般用来做首字大写以示醒目（如本篇开头 200%）；推荐多文字文章全局 120%
  • 标题或小标题也可以使用大些的 size 来凸显
  • 最好不要在正文中使用大号字体，会使行距疏疏密密，十分难看

效果预览

[size=190%]导[/size]读党的最爱… / [size=1%]舅舅党…[/size] 导读党的最爱，不过他们除了对首字放大有时还会加粗和上色.
舅舅党与忽略党的最爱.

3font 字体

语法

[font=字体名]文本[/font]

用途

  • 指定文字字体；字体其实用处不大，默认字体就很好看
  • 排版中使用了过多不同的字体，效果会看起来很乱

可用字体：simsun 宋体、simhei 黑体、Arial、Arial Black、Book Antiqua、Century Gothic、Comic Sans MS、Courier New、Georgia、Impact、Tahoma、Times New Roman、Trebuchet MS、Script MT Bold、Stencil、Verdana、Lucida Console

效果预览

[font=simsun]宋体[/font] / [font=simhei]黑体[/font] / [font=Arial]Arial[/font] 宋体 凉暮淡月可倾舟，覆水碧沉秋色流.

4b / u / i 粗体·下划线·斜体

语法

[b]粗体文本[/b]
[u]下划线文本[/u]
[i]斜体文本[/i]

用途

  • 粗体最常用：标题、小标题、标记、结论、首字大写等都可以使用
  • 下划线一般用于网址或邮件等文本，但又不宜直接使用链接标签的场合
  • 斜体用在一些特殊的场合（如引用、诗句）

效果预览

[b]粗[/b] / [u]下划线[/u] / [i]斜体[/i] 粗体文本　下划线文本　斜体文本

5align 对齐

语法

[align=left/center/right]文本[/align]

用途

  • 左 / 中 / 右对齐；默认左对齐，左对齐可省略标签
  • 中对齐一般用来做标题，也可用作署名；右对齐一般用来做署名
  • 图片、单元格等的对齐也可以嵌套使用该标签

效果预览

[align=center]…[/align]（官方渲染为块级居中）

这一行是右对齐
默认左对齐

6h 标题分割线

语法

[h]我是一条分割线[/h]
===我是一条分割线===

用途

  • 渲染为一条带标题文字的分割线；官方渲染为 h4.subtitle 粗体标题
  • 分割线上的文字可以是空格；可编写于文字两端或文尾
  • 分割线上的文字也可用其它文本标签嵌套修饰
  • 预览模式下看不到分割线

7l / r 左浮动·右浮动

语法

[l]左浮动段落[/l]
[r]右浮动段落[/r]

用途

  • 将段落左右浮动，实现图文左右配套的特殊效果
  • 左右浮动段落字节须等同，否则还是会自动平衡两侧

8list 列表

语法

[list]
[*]条目1
[*]条目2
[/list]

用途

  • 将整段文字缩进一段距离并进行分类；可嵌套使用，层次分明
  • 每个条目前增加 [*] 标签；嵌套最多三层，不同层级 [*] 显示三种不同样式
  • 可用来排版逐条计列的文本，也可使一段文本整体缩进

效果预览

三层嵌套 [list]（官方渲染为 ul.ulist 嵌套）
  • Did you think we had forgotten?
    • Did you think we had forgiven?
      • Behold, now, the terrible vengeance of the Forsaken!

10url 链接

语法

12code 代码

语法

13flash 视频

语法

用途

  • 嵌入视频播放框架；官方渲染为 640×360 视频占位 + 跳转链接

14table 表格

语法

[table]
[tr][td]单元格11[/td][td]单元格12[/td][/tr]
[tr][td]单元格21[/td][td]单元格22[/td][/tr]
[/table]

用途

  • table 指表格，tr 表示行，td 是单元格；每行单元格数必须相同，否则表格会乱
  • 单元格内可插入各种 BBS 代码：图片、链接、字体、对齐等
  • 列宽可在第一行 td 中加数字设定：[td50] = 宽度 50%（官方渲染 width:50%）；行高自适应
  • 编辑技巧：记事本中每行开头插 1、单元格间用 2 分隔、行末补 3，再用替换功能换成 BBS 代码

效果预览

官方渲染：tablecontainer 包裹，td padding 6px；[td50] → width:50%
颜色名样本
skyblueskyblue 天蓝色
redred 红色

15tid / pid 主题 ID·回复 ID

语法

[tid]主题ID[/tid]
[tid=主题ID]显示名称[/tid]
[pid]回复ID[/pid]
[pid=回复ID]显示名称[/pid]

用途

  • 主题帖地址栏 tid= 后的数字为主题 ID；回复帖地址栏 pid= 后的数字为回复 ID
  • 可在帖子中引用另一主题的回复（如银色黎明投诉其他版区）
  • 点击引用按钮时，回复第一句话是系统加上的 [pid][/pid] 代码

效果预览

官方渲染为链接 主题链接 [tid=123]　回复链接 [pid=456]

21排版界面的使用

  • 字体 / 字号 / 颜色的代码可直接使用排版界面中的下拉列表框选取和自动完成
  • 不清楚的代码可点击排版界面中的相关标签获得帮助；预览功能可提前观看排版效果
  • 误关页面后可用「恢复上次输入的内容」复原未保存的帖子
  • 每个帖子的长度上限是 40000 字节，可通过标签获知当前帖子的长度

22心得分享

  • 最重要的一点是学习别人的长处，多看看他人优秀的文章排版
  • 帖子的美观并不在于多么花俏，做到整洁干净，或多一点「清秀」的感觉就很不错了
  • 文章编辑中的半角空格是无效的，可以尝试用全角空格，或者 2 次 TAB 键
  • 较长篇幅的帖子中，多使用 LIST 列表会使文章条理看起来更清晰
  • 除了排版美观，真正的内涵在于文字内容看起来要文艺，整贴才会真正优秀
