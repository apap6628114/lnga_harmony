# 为什么把 NGA 域名集中收敛为单一事实源

## 背景

2026-08-05 NGA 将图片 CDN 从 `nga.178.com` 切换到 `nga.cn`，旧图片域 TLS 服务停止，App 全部图片加载失败（`CURLcode result 35`）。排查发现域名散落硬编码于 10+ 文件：

- **API 站点域**：`NgaClient.ets` 本地 `DOMAINS` 数组（3 个域名，轮换重试用）
- **CDN 图片域**：`AttachUrl.ets`、`Utils.ets`、`AuthApi.ets`、`TopicParser.ets`、`CommunityPanel.ets`（6 处）、`SearchPanel.ets`
- **链接识别列表**：`LinkUtils.ets` 与 `WebViewPanel.ets` **复制粘贴**两份 `NGA_DOMAINS`（后者还重复实现 `isNgaDomain`/`extractHostname`）
- **设置页域名选项**：`Constants.ets` `DOMAIN_OPTIONS`，与请求域名列表各自维护
- **TS 镜像工程** `tools/bbcode-ts`：`AttachUrl.ts`、`Utils.ts` 仍是旧域
- **文档** `.wiki`：`NGA_CDN_BASE` 引用旧值

每次切域需逐处替换，极易遗漏（本次就有 TS 镜像与文档残留），且 `WebViewPanel` 与 `LinkUtils` 两处列表"保持同步"靠注释约定，无强制。

另发现 `ForumApi` 版块搜索硬编码 `http://bbs.nga.cn`（http 明文 + 绕过 `DOMAINS` 轮换，bbs.nga.cn 故障时搜索不切备用域）。

## 方案对比

| 方案 | 优势 | 劣势 |
|------|------|------|
| 新建 `NgaDomains.ets` 单一事实源 + 全量收敛 + 逻辑去重 ✅ | 切域只改一处；host/API 域派生保证一致；`isNgaDomain` 单一实现；`DOMAIN_OPTIONS` 派生同步 | 改动面大（12 文件），需编译验证 |
| 最小修复（仅修 ForumApi、bbcode-ts、文档） | 改动小、风险低 | 下次切域仍要逐处替换，重复定义继续漂移 |
| 运行时动态探测域名 | 无需手工维护 | 需网络请求探测，复杂且违反"保守"原则；当前域名 301 存活，无此必要 |

## 决策

新建 `entry/src/main/ets/common/constants/NgaDomains.ets` 作为唯一事实源：

- `NGA_HOSTS`：纯 host 列表（链接识别用）
- `NGA_API_DOMAINS`：由 `NGA_HOSTS` 加 `https://` 前缀派生（请求轮换用，NgaClient 以 `import { NGA_API_DOMAINS as DOMAINS }` 引用）
- `NGA_IMG_BASE` / `NGA_IMG4_BASE` / `NGA_UPLOAD_URL` / `NGA_AVATAR_BASE`：CDN 域
- `DOMAIN_OPTIONS`（`Constants.ets`）由 `NGA_HOSTS` map 派生，保证设置项与请求列表一致
- `WebViewPanel` 删除重复的 `NGA_DOMAINS`/`isNgaDomain`/`extractHostname`，复用 `LinkUtils.isNgaDomain` 与 `UrlUtils.extractHostname`
- `ForumApi` 搜索改走 `ngaClient.get` 默认通道（https + 轮换）
- TS 镜像与 `.wiki` 同步切域

## 理由

1. **单一事实源**：域名定义与派生物（API 域、设置选项、识别列表）从一个数组出发，切域时不可能出现"请求已换、识别列表没换"的错位
2. **消除重复实现**：`WebViewPanel` 与 `LinkUtils` 的 `isNgaDomain` 逻辑逐字相同（lowercase + 精确/子域后缀匹配），合并后行为不变
3. **历史教训**：本次切域就有 3 类残留（TS 镜像、文档、`ForumApi` http 固定域），收敛后此类残留不再可能
4. **`origin_domain` 表单值**（`bbs.ngacn.cc`）为服务端约定字段而非连接域名，不纳入收敛，加注释防误改

## 代价

- 新增一个常量文件与一层间接（`NGA_CDN_BASE = NGA_IMG_BASE + '/attachments'`）
- `DOMAIN_OPTIONS` 从字面量改为 map 派生，若未来要"标签与 host 不同"（如中文化域名选项）需改回显式定义
- `nga.178.com` 在 `NGA_HOSTS` 中保留（301 仍存活，兼容旧链接识别），NGA 若彻底下线该域需从列表移除
